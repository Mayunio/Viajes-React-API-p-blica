1. El navegador abre index_actualizado.html
2. Carga los estilos CSS
3. Carga React desde internet <script src="https://unpkg.com/react@18/umd/react.production.min.js"></script>
4. Carga ReactDOM desde internet <script src="https://unpkg.com/react-dom@18/umd/react-dom.production.min.js"></script>
5. Carga Babel desde internet <script src="https://unpkg.com/@babel/standalone/babel.min.js"></script>
6. Lee archivo react_components.jsx
7. Babel traduce el JSX a JavaScript normal
8. React crea los componentes
9. ReactDOM los inserta dentro de los div vacíos del HTML
10. Se muestran los componentes en la página
